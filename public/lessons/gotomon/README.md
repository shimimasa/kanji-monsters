# ゴトモンと学ぶ授業ゲーム

広場の「理科・社会の旅」から開く2作品。元教材 `public/lessons/elementgirl/` の学習内容と案内役をもとに、子どもの操作で結果が変わるゲームへ作り直した。設計は `docs/lesson-pilot/game-design-v2.md`。元のHTMLと印刷シートは比較・出典確認のため残す。

- クルル：発電機を回し、電気の行き先をつなぎ、同じ電気で豆電球とLEDを時間経過で比べ、点灯ルールを試して小道を照らす。
- ヒョウ：村の3か所を訪ね、選挙権の歴史を年表で見て、秘密投票所を作り、参加人数による開票を比べて一票を入れる。投票先は保存・採点しない。
- 各場面の星は操作して結果を観察し「進む」を押したときだけ送る。最適な結果や投票先は条件にしない。5場面のあと、まとめ画面で本人が「仲間になる」を押すと完走を親画面へ送る。
- 星の最高数、捕獲、図鑑登録は既存のヨミタビ側に任せる。漢字の読みの学習記録は更新しない。
- 現在の画面は `lesson-game-v2.js` と `lesson-model-v2.js`、`lesson-game-v2.css`。旧試作の `lesson-game.js` と `lesson-game.css` は比較用で、HTMLからは読み込まない。
