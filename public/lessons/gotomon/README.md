# ゴトモンと学ぶ授業の試作

広場の「理科・社会の旅」から開く2作品。元教材 `public/lessons/elementgirl/` の学習内容と案内役をもとに、ゴトモンと試して結果を比べる短い冒険へ作り直した。元のHTMLと印刷シートは比較・出典確認のため残す。

- クルル：発電時の電圧、蓄電、豆電球とLED、センサーを試し、最後に夜の小道への給電計画を選ぶ。ジッケルも実験を手伝う。
- ヒョウ：カワワタ・オネガミ・チズリンの願いを聞き、選挙権の歴史、秘密投票、投票率の例を比べ、自分の一票を選ぶ。投票先は採点しない。
- 各場面の星は、必要な比較や声を見て「進む」を押したときだけ送る。5場面のあと、まとめ画面で本人が「なかまになる」を押すと完走を親画面へ送る。正答率・時間・音では決めない。
- 星の最高数、捕獲、図鑑登録は既存のヨミタビ側に任せる。漢字の読みの学習記録は更新しない。
