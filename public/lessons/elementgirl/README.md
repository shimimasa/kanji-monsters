# 理科・社会の旅：初回移植

元作品: [shimimasa/elementgirl-lesson](https://github.com/shimimasa/elementgirl-lesson)、コミット `25ae109a36c166e3395c540e85b30f0dfbaa02aa`。

このフォルダーには「クルルの発電所」と「ひとつぶ村」の授業本編と印刷用きろくシートを置く。本編の物語、実験、問題、SVGの案内役は元作品から移植した。再取得は `node scripts/one-off/import-elementgirl-pilot.mjs <元リポジトリ>` を使う。

ヨミタビ用の調整は、独立した認証・プロフィール・進捗保存・横向き制限を外し、`lesson-bridge.js` で集めた星とまとめへの到達を親画面へ伝える処理、スマホ縦の配置、先生用スキップの非表示とURLスキップの停止、間違えたときの穏やかな案内である。星の最高数・捕獲・図鑑登録は親アプリの確認済みセーブで行い、このHTMLから漢字の読みの学習記録は変更しない。効果音の大きさはヨミタビの設定に合わせる。

授業本編には動画への任意のリンクがある。動画は授業を進める条件にしていない。きろくシートは親画面の「きろくシート」から別タブで開ける。
