# 答えた後の操作を相棒に任せる（2026-10-05）

## 変更

- おしだし：答えの箱を選んだ後に「ここから はこんでもらう」を表示する。押すと相棒が箱を巣穴へ運び、その部屋を進める。自分で押す遊びも続けられる。
- ブロックくずし：答えのブロックを選んだ後に「あいぼうに あててもらう」を表示する。押すと選んだブロックが割れ、次の問題へ進める。ボールとパドルで狙う遊びも続けられる。
- どちらも相棒ボタンは回答後にだけ使える。新しい正誤イベントは出さず、従来の完了とごほうびの仕組みで最後まで進める。
