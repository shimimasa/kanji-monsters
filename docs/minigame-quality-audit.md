# ミニゲーム40本 品質点検（2026-10-01）

学習の質（何を学ぶか・記録が正しいか）と、ゲーム性（遊びとして成り立つか）を、40本同じ物差しで点検した記録。
コードとシミュレーション（反応の遅れや操作のぶれを入れた子どもらしいボット）で判断できることは直し、
子どもが遊ぶ様子を見ないと判断できないことは「見たいこと」に残した。

## 物差し

1. **記録の公平さ**：答えを知っている子が、ねらい・操作・時間のせいで「まちがい」と記録されないか。
   何も答えていないのに記録されないか。
2. **答え方**：選ぶ（再認）か、自分で組み立てる・入力する（再生）か。再生のほうが記憶に残る。
3. **問題の質**：まちがいの選択肢が「考えないと外せない」ものか。例文などの元データが正しいか。
4. **ふりかえり**：まちがえたときに、何がちがったか・答えは何かを示すか。
5. **ゲーム性**：自分で決める場面があるか、負けがなく最後まで進めるか、時間の長さ。
