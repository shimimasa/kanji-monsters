# しんかのへや（2026-10-05）

## 子どもの動線

1. ミニゲーム広場の、あいぼうの名前とレベルが見える帯から「しんかのへや」へ入る。シール帳からも入れる。
2. 自分のゴトモンを選び、Lv5までのXPと進化前の姿を見る。Lv5前なら、あと何XPかを表示する。
3. Lv5で「しんかさせる！」を自分で押す。進化音と光の演出の後、進化前と進化後の姿を並べて見る。
4. 進化前の姿で遊びたいときは専用画面で戻せる。Lv5の条件は消えない。

ミニゲームでLv5に達した結果画面には「しんかのへやへ」を出し、そのゴトモンを選んだ状態で専用画面を開く。進化可能になっただけでは姿を変えず、子どもの操作で変える。保存には既存の `companions[id].look.evolve` と `gotomonService.setLook` を使い、セーブ形式・学習記録・正誤判定は変更していない。

## 41種類のレビューから一緒に直したこと

おしだし、ぽいけんランド、川わたり、ミニゴルフ、おにごっこ、ジャンプ、レース、リズムたいこ、ブロックくずしの9種類は、プレイ時間が操作量で大きく変わる。広場の「約2分」「約4分」を、10へや・12ステージ・12問・12ホールという実際の区切りに替えた。子どもがかかる時間を自動操作の速さから推測しないため。

## 確認

- PC 1280×800とスマホ390×844の両方で、Lv5直前とLv5到達後の表示、進化操作、保存された姿、進化前の姿への切り替え、シール帳からの入口を操作した。4条件でブラウザ例外0件。
- Lv5まであと1XPの試験用セーブでミニゲームを完了し、結果画面の進化ボタンから専用画面へ進んだ。獲得10XPでLv5になり、保存後のXPは369→379だった。
- 試験用セーブはブラウザの独立したコンテキストを使った。実際の子どもの記録は変更していない。
- 子どもの試遊では、入口を自力で見つけられるか、進化前後の絵が変化として伝わるか、演出が心地よいかを観察する。
