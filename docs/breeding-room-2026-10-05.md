# はいごうのへや（2026-10-05）

## 配合のしくみ

- 伝説のゴトモン120ひきに、それぞれ固定のレシピがある。運で結果が変わることはない。
- レシピは「伝説がいる地方のタイプA（Lv5以上）1ひき」＋「どこの地方でもよいタイプB（Lv5以上）1ひき」。2ひきは別のゴトモンを選ぶ。
- その地方のゴトモンを1ぴき仲間にすると、その地方のレシピが見える。会う前の伝説は「？？？」で表示する。
- 配合すると伝説のゴトモンが仲間になる。親2ひきは使い切られず、レベルもそのまま。できたゴトモンは、希望すればあいぼうに選べる。
- 配合は仲間集めの仕組み。答えの正誤や学習記録の処理は変えない。

## 画面の流れ

1. 地方を選ぶ。
2. 会いたい伝説と必要なタイプを見る。
3. それぞれの条件に合う親を選ぶ。選んだ親の姿・名前・レベルを見比べられる。
4. 「この2ひきで であわせる！」を押す。仲間になった伝説と、親がそのまま残ることを案内する。

レシピがまだ見えないときは、その地方のゴトモンと仲間になると見つかることを表示する。レシピが見えても親が足りないときは、必要なタイプごとの候補数とLv5以上が条件であることを表示する。
