#### (1) Firestoreのセキュリティルール ← 最優先

匿名認証で実在の児童のデータが乗るので、ここだけ性質が違う（他はやり直せるが、これは漏れたら戻せない）。

- **調査済みの事実**: 書き込み先は**すべて `users/{uid}/...` の下**。

- **やること**: `firestore.rules` をリポジトリに作り、`firebase.json` に配線する。内容は次の1本で足りる:

  ```
  rules_version = '2';
  service cloud.firestore {
    match /databases/{database}/documents {
      match /users/{userId}/{document=**} {
        allow read, write: if request.auth != null && request.auth.uid == userId;
      }
    }
  }
  ```

- **ユーザーの作業（AI ではできない）**: Firebaseコンソールで現行ルールを確認し、上と差があれば
  `firebase deploy --only firestore:rules` で反映する。`npm run deploy` は `--only hosting` なので影響しない
