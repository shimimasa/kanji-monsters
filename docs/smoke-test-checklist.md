# スモークテスト・チェックリスト

リファクタリング・機能変更の各フェーズ完了時に、このリストを手動で通すこと。
（refactoring-plan.md Phase 0-2 の成果物。所要目安: 15〜20分）

## 1. 起動〜画面遷移

- [ ] `npm run dev` で起動し、bootProgress（進捗バー）→タイトルが表示される
- [ ] 新規状態（localStorage空）でタイトル「スタート」→ 名前入力画面 → 入力欄が漢字ボックスの枠に重なって表示される
- [ ] 名前を入れて「けってい」→ コース選択画面に遷移する
- [ ] 空欄や6文字以上で「けってい」→ alertではなく画面内メッセージが出る
- [ ] 既存プレイヤーではタイトルに「つづきから」「ようこそ○○さん」が出る
- [ ] コース選択 → 日本編 → 地方選択 → ステージ選択 → ステージを2回タップ → stageLoading → バトル開始
- [ ] コース選択 → 世界編 → 大陸選択 → 世界ステージ選択 → バトル開始

## 2. バトル

- [ ] 正解: エフェクト・ダメージ・ログ表示。読みちがい: 「おしい！」系の文言（「しっぱい」が出ない）
- [ ] 読みちがい時、入力欄が琥珀色に点滅し、「さっきためしたよみ」が青系の枠で表示される
- [ ] ヒント4段階（画数→読み一部→意味→読み全部）
- [ ] かいふく: 正解で回復、上限到達で alert ではなくゲーム内ログが出る
- [ ] 弱点（音読み/訓読み）ヒットで大ダメージ、ボスのシールドが削れる
- [ ] 左上「もどる」→ ステージ選択に戻る
- [ ] 左上「れんしゅうへ」→ 同じステージの練習モードに切り替わる
- [ ] 勝利 → 捕獲画面（最大4体・未収集が先頭）→ 勝利画面
- [ ] 勝利画面: 「✨はじめて読めた漢字」の行、「つぎの旅でまた会う漢字」パネル、「いま おぼえちゃう！」ボタン
- [ ] 敗北 → 夕暮れの「今回はここまで！」画面（嵐・絶望演出が出ない）→ リトライ/ちずにもどる/タイトルへ が機能する

## 3. 練習・復習

- [ ] ステージ選択でステージ選択 → 「マスター」→ 練習バトル（敵なし・HP減なし）
- [ ] 練習で読みちがい → その漢字が復習キューに入る（総復習モードの「今日の復習」に出る）
- [ ] 勝利画面「いま おぼえちゃう！」→ クイック復習が起動する
- [ ] 総復習モード（地方選択で総復習）→ 「今日の復習に挑戦！」が機能する

## 4. 図鑑・実績・プロフィール

- [ ] 漢字図鑑: 収集率、ソート（学年/画数/習得順）、フィルタが動く
- [ ] 漢字図鑑の詳細モーダルに「がくしゅうのきろく」（✓つき読み・よめた回数・バー）が表示される
- [ ] モンスター図鑑: サムネイル遅延読み込み、地方フィルタ
- [ ] プロフィール: 「こんしゅうのがんばり」カード（今週の回数と先週比）が表示される
- [ ] 実績解除の通知が出る（例: 敵を10体倒す）

## 5. セーブ・復元

- [ ] バトルで数問解答 → リロード → プロフィールの学習記録（よめた回数）が残っている
- [ ] 敗北 → リロード → 敗北までの学習記録が残っている
- [ ] 設定（音量・回復回数・敵の行動タイミング）がリロード後も維持される
- [ ] 設定画面のエクスポート → インポートで復元できる

## 6. スマホ（実機またはDevToolsエミュレーション）

- [ ] 縦持ちで黒帯領域のタップが無視される（誤タップしない）

- [ ] 名前入力画面でも入力欄が正しい位置に出る
